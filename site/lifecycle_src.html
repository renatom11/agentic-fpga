One project, start to finish

This page follows one FPGA project end to end: uart_lite, a fixed-rate 115200 baud 8N1 serial port for a 50 MHz board, five modules, built by AI agents under one human sponsor. Thirty-nine beats, from an empty repository to a signed-off receiver. Press play, or drag the scrubber. Click any box in the repository to see what is inside it at that point on the timeline.

Why a UART here, and not the NIC

The programme this organisation exists to build is the 10G trading network card documented across the rest of this site — and it is not finished, so it cannot yet be shown end to end. A walkthrough built from it today would stop in the middle of a module: that demonstrates a method working, not a method completing. uart_lite was chosen because it is small enough to carry the whole way — specification, review, a testbench written blind from the spec, a real bug caught, a mutation campaign against the benches themselves, and a passing suite in CI — inside one finished project, in its own repository, so the demonstration and the NIC programme never contaminate each other. What you are watching is the method, shown whole on a design that fits. The NIC is where the same seats, the same protocol and the same gates are doing the work that is still in progress; the backlog is where that work reports its real state.
