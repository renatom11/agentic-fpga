## Where the Council Clashes

**FAIL versus PASS WITH CONDITIONS.** The Contrarian argues FAIL under Sal's own mechanics: C5 fails at its first, middle, and last step, and C2 carries an execution-verified false record claim (§2.7's "owed test cases still unapplied," refuted by Bob F1 at commit a0454b4 — the tests exist, run green, and are counted inside §6.3's own fifty-one). Everyone else lands PASS WITH CONDITIONS: the defects are localized, enumerated, and repairable in days without weakening a single claim — Sal's only permitted repair direction — and the verified core is precisely the part that is hardest to build. Both positions are honest readings of the same evidence; they differ on whether a verdict grades the artifact as handed or the distance to repair. The chairman resolves this below.

**Prose-complete mechanism versus fission.** Sal's C5.3 demands prose complete enough that a reimplementation refuses the same commits; Charlie, Bill, the Outsider, and the Executor demand anonymized format blocks in the body. The First Principles Thinker argues the opposite: a prose mirror of the rule set is a second, unverifiable copy — §2.4's "rule and its check that disagree" manufactured one level up — and mechanism belongs in the shell as testable artifacts, referenced, not paraphrased. Both are right about a real hazard: under-determination if the shell link breaks, drift if the prose duplicates it. The resolution is not a compromise but a structure, given in the Recommendation.

**Does naming the shell dissolve the criticals?** Bill: "with the shell in hand, F1/F6 dissolve." The Contrarian, standing on Bob F4: no — the shell is already thirty-one commits ahead, governed by a federation law the document never mentions, and §6.0's "kept deliberately frozen" is false against commit 7fb2c99. Naming without the drift check converts an absence into a silent contradiction, which §2.4 itself rates worse. The Contrarian wins this one on the record.

**What the fork does with the errata.** First Principles: the stamped, margined edition is this program's audit record — declare it program-local, strip on fork. Executor and Outsider: keep the corrections, they are the reasons; layer them. Expansionist: keep them and build stamp-migration tooling. All three positions preserve truth; they price the maintenance liability differently.

**Whether the three surviving falsehoods are cheap edits or a process verdict.** The Executor: their operational cost to an adopter is near zero; fix them and spend the budget on the §6 halts. The Contrarian: three recurrences of the promised-purged class, in the edition produced to purge it, prove the production process cannot detect this class — so the cure must be a mechanism, not more careful prose. The chairman sides with both: fix the sentences, and adopt the mechanism (see below), because per-claim editing of a 3,000-line prose mirror demonstrably does not converge.

**The drift check is assigned to the wrong party.** §6.0 calls the doc-shell drift check "the most useful thing an adopter could build first." The Executor named what no auditor did: the exporter holds both halves of the export unit; the adopter holds one. **The document fails its own root class at its own boundary.** The Contrarian assembled what B.6 half-confesses: written by the specification lead, stamped by the program's own auditor, confirmed by a round in which each seat confirms the description of *its own* discipline, never through the packet lifecycle it describes, no external anchor anywhere — while §1.4(e), this edition's own ship-blocker, forbids exactly that for any model that grades. **Reality has already built the export mechanism the document doesn't describe.** The First Principles Thinker reframed Bob F4 from gap to inverted dependency: the record contains a working transfer pipeline — shell repo, seeded LESSONS corpus, HT- transits as inbox PRs under a federation law with no privileged lane for the origin — invisible in the chapter about exporting. ## The Recommendation

**PASS WITH CONDITIONS — the conditions precedent, mandatory, and re-verified, meaning: this document may not be handed to an adopter or described as "replication-grade" until they are discharged.** A bare FAIL would misdescribe an artifact whose enforcement core survived hostile re-execution and whose rationale layer every reviewer certified; but an unconditional pass would ratify a bootstrap that has never run and an evidentiary spine that covers half the text. The conditions are document revisions, by section:

**Tier 1 — truth repairs (C2/C7 veto class; hours of work).**
- **§2.7:** delete the false limb "its owed test cases still unapplied" — they landed (S29–S37, green, inside §6.3's own count). State the surviving true limb (constitutional diffs unapplied) alone.
- **§4.7 and §3.10:** add the sponsor's fifth standing power — candidate-by-candidate refusal at the lessons harvest — and strike "completely enumerated" or make it true.
