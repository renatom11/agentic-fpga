**Adoption-grade, not replication-grade.** A competent team holding this document *plus a verified clone of the shell plus this repository* can stand the organization up: the third edition repaired the catastrophic gaps the executed adoption run found (the shell is now named, twelve FACSIMILE blocks carry the machine-parsed grammars, §6.2 is machinery-first, the solo-adopter dead ends are honestly foreclosed).
